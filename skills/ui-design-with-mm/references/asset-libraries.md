# Asset library defaults

Read this reference when brand assets do not provide an icon set or illustration system. Brand guidelines and existing product assets remain primary evidence.

## Icons

Propose **Phosphor** as the default established icon library when no brand icon set exists, subject to user approval and current host/package availability. Fix one Phosphor weight, size grid, optical alignment rule, and corner treatment for the product. Keep icons as reusable library components and use semantic color tokens. Do not mix Phosphor with another icon family or use loose vectors to fill a gap.

## Illustrations

If the brand has no illustration system, propose one source and one style through the choice layer. Candidate sources include unDraw, Open Doodles, Humaaans, Open Peeps, IRA Design, and Blush collections. These are source options, not a license to mix styles. Verify the current collection's license, editability, attribution requirements, and availability before use.

For the chosen source, document the illustration style, color mapping through semantic tokens, line weight, level of detail, and where placeholders remain. Blush is a collection platform; a specific Blush collection still needs its own style and license decision.

# Personal theme template

Read when initializing `theme.md`. The file is private to the user, git-ignored, and never shared. Start from this template. Do not copy any value from a reference or from another user's theme.

Use `theme.md` beside `SKILL.md` in a personal install unless the user supplies another private location. Never overwrite an existing theme with the template.

## Empty file template

```markdown
# Personal theme

Applies to this user's own work. A named product's brand and accessibility take precedence.

No theme recorded yet.

## Character
[How the design should feel, in the user's words.]

## Type
[Families, scale, weights, tracking, where each is used.]

## Color behavior
[Palette and how it is used: surfaces, accents, status, dark mode.]

## Shape and surface
[Radius, borders, elevation, density.]

## Iconography and imagery
[Icon set, weight, illustration or photo treatment.]

## Motion
[Curves, durations, what animates and what does not.]

## Patterns
[Navigation, cards, forms, disclosure, data display conventions. Control sizes: minimum hit area (default 48 px, never below 24), checkbox and radio size, toggle size.]

## Excluded
[What this theme never does.]
```

## Rules

- Record only what the user states or approves. Do not invent a theme from generated work.
- Mark anything drafted by the learn intent as observed, inferred, or unverified until the user confirms it.
- Keep it out of commits, ZIPs for sharing, Figma content, and research queries. No collection, telemetry, export, or sync is implemented.
- Accessibility checks always apply, whatever the theme says.

## New in css/nsimbi.css (marked new)

- `.ns-stage`: a figure inset variant, the Moniepoint hatch with two phones under chips (`.ns-chip`, `.ns-chip--dark`, reusing `.mv-phone-chip`).
- `.ns-device`: a CSS-drawn graphite iPhone frame, sized in cqw, with an optional auto-scroll (`data-ns-scroll`, `data-focus`) and a status-bar scrim.
- `.ns-fig .ns-orig`: the phone cut out of Felix Kitaka's recording.

## Conventions and gotchas

- `.case-figure img { width: 100% }` overrides plain classes, so anything inside a figure needs a `.ns-fig .x` selector.
- Heredocs with apostrophes break in the Windows shell: write scripts to files.
- The Nsimbi page is generated by a script kept in the session scratchpad; the HTML is the source of truth.
- `images/omnione/omnione-design-system-cover-banner.png` is still used by the Work card and the home shelf; only the Omnione hero stopped using it.

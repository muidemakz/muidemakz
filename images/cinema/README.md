# Case-study media

Original product screenshots are embedded in native SVG compositions. Studio plates are generated. Omnione and Fundall retain their original hero banners and catalogue covers. The unused patterned Omnione variation remains available for review.

Coreloops and Cardtonic have animated hero previews. Six body walkthroughs cover Omnione, Fundall, Teesas, Coreloops, Cardtonic and VENX. Screen names appear left of slim progress indicators. No visible Play/Pause or numbered walkthrough buttons. Previews advance automatically while visible and pause on mouse hover, keyboard focus or a hidden tab. Reduced motion defaults to still frames with manual screen selection.

Valideity uses the cinematic brand-and-display illustration with a smaller logo. Historical evidence screenshots remain in the case body.

Teesas uses a generated classroom photograph with a realistic laptop. The original interface is embedded inside the laptop screen, excluding the old monitor bezel and grey background. The institution header remains visible; the laptop viewport shows the upper page and the original case-body screenshots remain intact. Its homepage and catalogue covers match.
